# Brainrot Fuck Departmant

## GitHub'a kurulum
1. GitHub'da yeni bir depo açın (ör. `brainrot-site`).
2. Bu klasördeki tüm dosyaları (index.html, admin.html, style.css, data.json, logo.png) deponun köküne yükleyin.
3. Depo → Settings → Pages → Branch: `main` / root → Save. Site `https://KULLANICI.github.io/brainrot-site/` adresinde açılır.
4. Kendi logonuzu `logo.png` adıyla değiştirin.

## Admin panel
1. GitHub → Settings → Developer settings → Fine-grained tokens → yalnızca bu depo, **Contents: Read and write**.
2. `siteniz/admin.html` adresine gidin, kullanıcı adı, depo adı ve token'ı girin.
3. Karakter / ekip ekleyin-silin, "Biz Kimiz"i düzenleyin, görsel yükleyin → **Kaydet**. Görseller `images/` klasörüne yüklenir.

Token'ı kimseyle paylaşmayın; sadece tarayıcınızda kalır.
